# SYNORA - One Platform. Every Organization.

![SYNORA Logo](logo.png)

SYNORA is a modern, high-density Progressive Web App (PWA) designed to manage families, communities, and organizations seamlessly. Built with a mobile-first architecture, it provides an all-in-one digital hub for communication, financial tracking, and member management.

## ✨ Core Features
- **📱 PWA Ready**: Installable directly to mobile home screens.
- **💬 Organization Chat**: Real-time end-to-end organizational communication.
- **📊 Finance Dashboard**: High-density UI tracking Cash flow, Budgets, and Debts.
- **🏢 Directory & RBAC**: Smart member management with Role-Based Access Control.
- **🔗 Organization Merge**: Innovative "Absorb" logic to merge extended families or branches.
- **📓 Shared Notebook**: Collaborative space for organizational documentation.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, ES6 JavaScript
- **Reactivity**: [Alpine.js](https://alpinejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Database**: Firebase (Auth, Firestore Realtime Database)
- **Hosting**: [Vercel](https://vercel.com/)

## 🚀 Deployment
This project is optimized for instant deployment via Vercel. 
Simply push the code to GitHub and connect your repository to Vercel for continuous integration.
